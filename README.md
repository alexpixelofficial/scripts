# Удаление все подписок каналов youtube
Что бы запустить скрипт зайдите на вашу страницу подписок в данный момент она https://www.youtube.com/feed/channels в течении времени может поменяться.
Зайти в консоль разработчика и через вставку в консоли разработчика вставить скрипт, в firefox требует ввести "разрешить вставку" ручным вводом.
