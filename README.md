# 🛑 Автоматическое удаление всех подписок на YouTube

Скрипт для быстрой очистки вашего аккаунта YouTube от всех каналов, на которые вы подписаны. Работает прямо в браузере через консоль разработчика.

---

## 🚀 Инструкция по запуску

1. **Перейдите на страницу подписок:**  
   Откройте [YouTube Channels](https://www.youtube.com/feed/channels) *(ссылка актуальна на данный момент, но может измениться со временем)*.
2. **Откройте консоль разработчика:**  
   Нажмите `F12` (или `Ctrl + Shift + I` / `Cmd + Option + I` на Mac) и выберите вкладку **Консоль (Console)**.
3. **Разрешите вставку (только для Firefox):**  
   Если вы используете браузер Firefox, сначала введите вручную фразу `разрешить вставку` (или `allow pasting`), чтобы снять защиту безопасности.
4. **Запустите скрипт:**  
   Вставьте код скрипта в консоль и нажмите `Enter`.
